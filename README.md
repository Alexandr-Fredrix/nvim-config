# Neovim-конфигурация

Моя персональная сборка Neovim, настроенная вокруг менеджера плагинов [lazy.nvim](https://github.com/folke/lazy.nvim). Конфигурация ориентирована на повседневную разработку: комфортный интерфейс, удобный поиск, автодополнение, работа с Git и несколько собственных улучшений.

## Основные возможности
- **Оформление:** тема Tokyonight, настроенная статус- и таб-линиями (`lualine`, `bufferline`), аккуратные разделители, подсветка диагностик с рамками.
- **Навигация по проекту:** файловый менеджер `nvim-tree` с подсветкой Git, расширенный fuzzy-поиск через `telescope`.
- **Автодополнение:** `nvim-cmp`, `LuaSnip`, `friendly-snippets` и `nvim-autopairs` дают подсказки, сниппеты и автозакрытие скобок.
- **Подсветка и синтаксис:** `nvim-treesitter` (см. `lua/plugins/syntax.lua`) для современных подсветок и дополнительных возможностей.
- **Управление окнами:** `which-key` с русскоязычными подсказками клавиш, удобные бинды для буферов и сплитов.
- **Инструменты разработчика:** `gitsigns` и `vim-fugitive` для Git, `toggleterm` для терминалов, поддержка ansible/helm/yaml.
- **Пользовательские сниппеты:** директория `lua/snippets`, в том числе сниппет `userdocker` для Dockerfile.

## Требования
- Neovim 0.9+ (рекомендуется последняя стабильная версия).
- `git`, `ripgrep` (для поиска через telescope).
- Компилятор C (gcc/clang) и `make` для сборки некоторых плагинов.
- Опционально: `lazygit` для интеграции с терминалом.

## Установка
1. Сделайте резервную копию текущей конфигурации:  
   ```bash
   mv ~/.config/nvim ~/.config/nvim.backup
   ```
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Alexandr-Fredrix/nvim-config.git ~/.config/nvim
   ```
3. Запустите Neovim. `lazy.nvim` установит себя автоматически и предложит синхронизацию плагинов. Можно вручную запустить:
   ```vim
   :Lazy sync
   ```
4. Перезапустите Neovim после установки плагинов.

## Быстрые горячие клавиши
- `<leader>e` — открыть/закрыть `nvim-tree`.
- `<leader>ff` / `<leader>fg` — поиск файлов и live-grep через telescope.
- `<S-l>` / `<S-h>` — переключение буферов.
- `<leader>tt` — плавающее окно терминала (`toggleterm`), `<leader>tg` — `lazygit`.
- `<leader>cc` / `<leader>cb` — комментирование строк или блоков (`Comment.nvim`).
- `<leader>gs`, `<leader>gc`, `<leader>gp` — основные Git-команды (`vim-fugitive`).
- `userdocker<Tab>` в файле `Dockerfile` — вставка пользовательского сниппета.

Остальные бинды удобно подсмотрены через `<leader>?` (открывает `which-key`).

## Структура проекта
```
.
├── init.lua                 # Точка входа: загрузка настроек и lazy.nvim
├── lua/
│   ├── config/              # Опции (options.lua), клавиши (keymaps.lua), автокоманды
│   ├── plugins/             # Каталоги с группами плагинов: ui.lua, completion.lua, lsp.lua, syntax.lua
│   └── snippets/            # Пользовательские сниппеты (LuaSnip)
├── lazy-lock.json           # Файл блокировок плагинов для повторяемости установки
└── README.md                # Этот файл
```

## Пользовательские сниппеты
- `lua/snippets/dockerfile.lua` — содержит сниппет `userdocker`. Работает в файлах с типом `dockerfile`.
- Чтобы добавить новые сниппеты, создавайте файлы `*.lua` в каталоге `lua/snippets` и возвращайте таблицу со сниппетами от LuaSnip.
- После редактирования сниппетов выполните `:LuaSnipReload` или перезапустите Neovim.

## Обновление и сопровождение
- Курирует плагины `lazy.nvim`. Для обновления: `:Lazy update`.
- Проверить состояние плагинов: `:Lazy`.
- При необходимости можно временно отключать/настраивать плагины, редактируя соответствующие файлы внутри `lua/plugins/`.

## Полезные советы
- Включён режим относительных номеров строк, автосохранение по `<leader>ww`, быстрый выход `<leader>qq`.
- Диагностика LSP отображается с округлыми рамками, а статусбар показывает активный LSP клиент.
- Для удобной отладки настроек используйте `:checkhealth`.
